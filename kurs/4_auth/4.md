## Zadanie 4 - Autoryzacja i walidatory

#### Zadanie domowe

1. Rozszerz swój schemat Prisma o model `User`, potrzebny do obsługi logowania
   - Model powinien zawierać przynajmniej: email oraz hasło (hashowane)
   - Wykonaj migrację bazy danych po dodaniu modelu

2. Dodaj endpoint do rejestracji użytkownika
   - Pamiętaj o tym, aby zapisać hasło po hashowaniu, np. przy pomocy `bcrypt`:
     ```typescript
     import * as bcrypt from 'bcrypt';

     const hashedPassword = await bcrypt.hash(plainPassword, 10);
     ```
   - Zastanów się, jakie kody błędów powinny być zwracane? Np. 409 CONFLICT, gdy istnieje już użytkownik o podanym emailu:
     ```typescript
     throw new ConflictException('Użytkownik z tym adresem email już istnieje');
     ```

3. Dodaj endpoint do logowania, który zwraca token JWT
   - Przy generowaniu tokenu dodaj obecny znacznik czasu (`iat` jest dodawany automatycznie przez bibliotekę, ale możesz też dorzucić własne pole):
     ```typescript
     const payload = { sub: user.id, email: user.email, timestamp: Date.now() };
     const token = this.jwtService.sign(payload);
     ```
   - Dodaj zmienną środowiskową `EXPIRY_TIME_MS`, oznaczającą czas ważności tokenu w milisekundach.
   - Przy sprawdzaniu poprawności tokenu, sprawdź, czy jest jeszcze ważny (czy różnica między teraźniejszością a `timestamp` z tokenu nie przekracza `EXPIRY_TIME_MS`) - jeżeli nie jest, odeślij odpowiedni komunikat błędu, np.:
     ```typescript
     throw new UnauthorizedException('Token wygasł');
     ```

4. Zastanów się, które endpointy z Waszych dotychczasowych zasobów (`Trip`, `Expense`, `Participant`) powinny być dostępne publicznie (dla każdego), a które tylko dla osób zalogowanych
   - Podziel obecne endpointy na publiczne i prywatne, dodając zabezpieczenia (guardy) sprawdzające, czy użytkownik jest zalogowany:
     ```typescript
     @UseGuards(JwtAuthGuard)
     @Get()
     findAll() {
       // ...
     }
     ```
   - Zastanów się, które informacje powinny móc opuścić nasze API, a co powinno zostać jednak ukryte (sprawdź i zaaktualizuj swoje DTO z Zadania 3 pod tym względem).

5. Stwórz endpoint `PATCH /user`, który pozwala zalogowanemu użytkownikowi na aktualizację jedynie swoich własnych danych - dane zalogowanego użytkownika znajdziesz w `req.user` (dzięki Guardowi):
   ```typescript
   @UseGuards(JwtAuthGuard)
   @Patch('user')
   updateProfile(@Req() req, @Body() dto: UpdateUserDto) {
     return this.userService.update(req.user.id, dto);
   }
   ```

6. (Tylko dla chętnych) Dodaj do swojej aplikacji CORS. Skonfiguruj tak, aby akceptował połączenia z localhost i portów od `5000` do `5599` włącznie.
